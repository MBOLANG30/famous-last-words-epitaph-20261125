A one-line tombstone epitaph of famous last words for the make.fun bounty
"Famous Last Words: The Funniest Epitaph".

## The epitaph

## How it works

`main.ts` is a deterministic Node program that writes exactly that one line
(64 characters, single line, no trailing newline) to `/output/entry.txt`.

```sh
node main.ts
```
